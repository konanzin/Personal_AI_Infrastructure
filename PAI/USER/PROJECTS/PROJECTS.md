# Projects

> Bootstrap default — a small registry of active projects and routing aliases.

Use this file to tell the DA what projects exist, what they are called, and
where they live. Keep entries short and concrete.

## Format

```md
### Project Name
- **Slug:** short-id
- **Purpose:** one sentence on what it is
- **Path:** optional local path or repo name
- **Status:** active / paused / archived
- **Notes:** optional routing hints
```
